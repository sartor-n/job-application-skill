# Interview Prep Method

Each stage gets one prep sheet from `templates/interview/`, filled from `job_description.md`, `roast.md`, `resume.md`, `cover_letter.md`, `knowledge/`, and any earlier debriefs in the folder.

## Stage to template
| Stage | Template | Length of pitch |
|---|---|---|
| Recruiter or HR screen | recruiter_screen.md | 60 to 90 seconds |
| Hiring manager | hiring_manager.md | about 2 minutes |
| Panel, case, technical or presentation round | panel_or_case.md | per brief |
| Final round with executives | final_round.md | 60 to 90 seconds, calibrated |
| Reference check | reference_check.md | n/a |
| Offer or contract | offer_review.md | n/a |
| After any stage | debrief.md | n/a |

## Research rules
* Interviewer research uses public sources only (company site, public profiles, talks, articles). Ask the user before searching for a named person, and never store anything beyond role, tenure and public statements.
* Company research: recent results, strategy statements, product launches, org changes. Three to six specific bullets beat a page of generalities.

## Building the sheet
1. Fill the header (who, when, format).
2. Write the pitch first. It reuses the CV summary's lead differentiator and two proof points with numbers.
3. Map the JD's must-haves to one example each. Use a short STAR shape: situation, what you did, result with a number, one line on what you learned. Keep each to 90 seconds when spoken.
4. Draft the user's questions grouped by theme. Mark which decision each group informs (is the mandate real, is the bet conviction or narrative, how are decisions made, where does this role sit).
5. List the do-nots specific to this room.
6. Note salary facts: the band, the target, the walk-away. Never reopen a band already agreed.

## Rehearsal
Read the expanded answers the night before, never in the room. In the room, use only the skim sections (pitch, topic directions, question list).

## After
Fill `debrief.md` within an hour. Offer to save new facts about the user's own experience to `knowledge/`. Append a `stage_log` entry to `metadata.json` (stage, date, interviewer roles, outcome when known).
